    这些基础来源从原总览书目归入统一索引，用于回查静态表示、上下文预训练和早期目标，不表示已完成独立研读。

    对比目标与样本对加权¶

    跨论文的定义、梯度、候选与适用条件集中在 Embedding 损失函数精讲，下面保留可回查的原始来源。

    工作 原始来源 机制与本仓库入口
    N-pair Loss Sohn, NeurIPS 2016，原文 多负例候选分类；排序项的 softmax 与 log(1+…) 写法等价
    CPC／InfoNCE van den Oord et al., 2018，原文 上下文预测与候选分类；分母包含当前正例，互信息界需遵守采样假设
    MNRL 的配对检索来源 Henderson et al., 2017，原文 · Sentence Transformers 文档 同批其他配对文档作为假定负例；正负由当前查询决定，匹配项也在分母中
    Multi-Similarity Loss Wang et al., CVPR 2019，原文 · 作者代码 监督式度量学习，多个正负 pair 的 mining 与分别加权；完整公式和区别见 InfoNCE 精讲
    FaceNet／Triplet Schroff et al., CVPR 2015，原文 平方距离间隔、单位表示与 semi-hard 三元组采样；注意库实现的距离和 margin 单位
    SimCLR／NT-Xent Chen et al., ICML 2020，正式论文 · arXiv 两视图候选交叉熵；排除自身但保留正视图，另需关注投影头和数据增强
    Supervised Contrastive Learning／SupCon Khosla et al., NeurIPS 2020，原文 · 作者代码 同类多正例；outside-log 与 inside-log 不同，正例份额影响梯度和损失下界
    Circle Loss: A Unified Perspective of Pair Similarity Optimization Sun et al., CVPR 2020，原文 · 参考实现 根据相似度的优化状态自适应加权；参考代码不是官方实现，需检查 stop-gradient 约定
    Understanding Contrastive Representation Learning through Alignment and Uniformity on the Hypersphere Wang & Isola, ICML 2020，正式论文 · 原文 · 作者代码 单位球面的对齐与均匀性、渐近分析；区分期望的 log 与 log 的期望
    CosFace: Large Margin Cosine Loss for Deep Face Recognition Wang et al., CVPR 2018，原文 类别代理上的余弦 margin，不是样本文档候选的 MNRL
    ArcFace: Additive Angular Margin Loss for Deep Face Recognition Deng et al., CVPR 2019（预印本 2018），原文 角度 margin 分类；与 CosFace、Triplet 的 margin 单位不同

    奠基性论文与经典阅读顺序¶

    2026-10-22 增补：优先阅读“定义问题、建立可复用范式、影响后续方法”的论文。高引用是线索，不能替代方法与证据；这里不使用未经实时核验的 Google Scholar 引用数。下表中的“待独立研读”不等于仓库从未引用过它，也不表示已完成全文材料。

    论文与正式出处 为什么值得读 与现有材料的连接 / 覆盖
    DPR — Dense Passage Retrieval for Open-Domain Question Answering，EMNLP 2020，原文 直接监督的 BERT 双编码器结合同批负例、BM25 难负例，形成清晰可复用的开放域问答稠密检索基线 已有 精炼版、解读、全文对照；连接 ANCE、RocketQA、RAG
    DrQA — Reading Wikipedia to Answer Open-Domain Questions，ACL 2017，原文 把整部 Wikipedia 作为知识来源，建立高效检索与神经阅读器组合；理解“给定证据”和“自己找到证据”的差异 待独立研读；作为 DPR 的任务和数据处理前置
    ORQA — Latent Retrieval for Weakly Supervised Open Domain Question Answering，ACL 2019，原文 ICT 预训练与潜变量检索，尝试只依靠问题—答案监督训练开放检索问答 待独立研读；与 DPR 对照监督来源、段落编码器是否更新、联合训练成本
    REALM — Retrieval Augmented Language Model Pre-Training，ICML 2020，正式原文 把知识检索纳入语言模型预训练，理解外部知识与模型参数知识的分工、异步索引更新 优先独立研读；补上 DPR 的“无需额外检索预训练”所对应的另一条路线
    RAG — Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks，NeurIPS 2020，原文 连接参数记忆与非参数文档索引；RAG-Sequence / RAG-Token 明确检索文档如何进入生成概率 优先独立研读；区分原论文模型与今天泛称的 RAG 工程流水线
    FiD — Leveraging Passage Retrieval with Generative Models for Open Domain Question Answering，EACL 2021（预印本 2020），正式原文 段落各自编码、在解码器融合，研究怎样使用大量检索证据 优先独立研读；与 DPR 抽取式阅读器、RAG 文档边缘化形成对照
    BEIR — BEIR: A Heterogenous Benchmark for Zero-shot Evaluation of Information Retrieval Models，NeurIPS 2021 Datasets and Benchmarks，原文 用跨任务、跨领域评测检验检索泛化；说明为何 BM25 必须保留为强基线 现有多篇引用成绩，待独立研读评测原论文；不要只记一个平均分
    DSSM — Learning Deep Structured Semantic Models for Web Search using Clickthrough Data，CIKM 2013，Microsoft Research 从点击监督学习查询—文档共享语义空间，理解双塔搜索早于 BERT 的技术前史 待独立研读；与 DPR 比较监督、文本表示和候选负例
    InferSent — Supervised Learning of Universal Sentence Representations from Natural Language Inference Data，EMNLP 2017，原文 研究 NLI 监督能否迁移成通用句向量，帮助理解句子表示的训练目标与评测 待独立研读；连接已有 Sentence-BERT、SimCSE，区分语义关系与检索相关性

    已有材料继续进入这条经典线：Sentence-BERT、ANCE、ColBERT、SimCSE / Contriever / Condenser 合写。后两种“已有独立详解”和“已有合写/历史 zh.md”覆盖形态不同，不统一标成已完成当前格式的三份材料。

    建议先沿 DPR → RAG → FiD → BEIR 读出完整的“找到证据—利用证据—检验泛化”问题链，再用 DrQA → ORQA → REALM 补前史与另一种训练范式；DSSM、InferSent 用来解释为什么这些基础机制会出现。方法间的联系见总览的按问题回查，正文入口统一在阅读索引。

    弹性向量维度 Matryoshka Representation Learning（2022） 已有 独立精炼版 与 解读；尚无全文对照；总览补充截维、候选数与索引成本
    大 batch 训练 GradCache（2021） 已有 独立精炼版、解读及全文对照；回查表示梯度、分块重算和随机性一致性
    蒸馏与组 batch TAS-B（2021） GPL/蒸馏已有涉及；补主题感知和 margin 均衡采样，研究有限预算下如何使用教师信号
    Decoder 检索前史 SGPT（2022）；RepLLaMA / RankLLaMA（2023 / SIGIR 2024） 已有零散引用；连接 E5-Mistral、LLM2Vec 和 Qwen3，比较池化、任务适配与重排
    评测设计 BEIR（2021）；MTEB（2022 / EACL 2023）；MMTEB（2025） 已大量使用结果；应专门研究任务构成、跨域/跨语覆盖、指标及平均分聚合，固定版本再比较
    推理密集检索 BRIGHT（2024）；ReasonIR（2025） 待补主线；从检索能力缺口读到困难查询和负例合成，承接 InPars/E5-Mistral
    指令跟随检索 FollowIR（2024） 已有 独立精炼版、解读及全文对照；总览将指令相关性与输入模板区分
    语料上下文表示 Contextual Document Embeddings（2024 / ICLR 2025） 待补；邻近文档进入训练目标和表示架构，与文档内部 late chunking 对照
    文档内部上下文 Context is Gold / ConTEB / InSeNT（2025） 待补；用上下文依赖检索评测及同序列负例训练，验证 late chunking 是否真正利用文档信息
    查询时生成增强 HyDE（2022 / ACL 2023） 已有 独立精炼版、解读及全文对照；比较查询时生成与离线训练的成本和漂移
    长文档检索 LongEmbed（EMNLP 2024） 已有 独立精炼版、解读及全文对照；结合 YaRN 区分窗口扩展和有效信息保留
    多向量训练与引擎 XTR（NeurIPS 2023）；WARP（2025） 待补；接 PLAID，研究重要 token 召回、相似度估计、隐式解压和聚合
    多向量固定维编码 MUVERA（NeurIPS 2024） 待补；用非对称固定维编码近似集合相似度，权衡维度、误差、候选召回及重排
    图文数据筛选 DataComp（NeurIPS 2023） MegaPairs 的数据来源已有涉及；固定训练配方和预算，比较数据筛选方法
    高效图文学生 MobileCLIP（CVPR 2024）；MobileCLIP2（2025） 仅简短提及；教师 caption/特征离线写入增强数据，与 ≤0.6B 自训和多教师蒸馏目标直接相关

    方法之间的关系¶

    下面的箭头表示研究问题的承接或系列迭代，并非全部存在权重、架构或数据继承关系。例如 E5 与 GTE 是可对照的独立路线。

    稠密单向量：  E5 → GTE → gte-Qwen2 / E5-Mistral
              Nomic（长上下文、数据可复现）
              LLM2Vec（Decoder 改成双向）
              Conan-v1（BERT + 动态难负例）→ Conan-v2（从零训 LLM）
              QZhou（双向 Qwen2.5-7B）
              Token Prepending（不训练，补因果注意力）

多向量迟交互： ColBERT → ColBERTv2 → PLAID
                 └→ ColPali → ColQwen2 → ColQwen2.5 → ColQwen3
                    （ColQwen 无独立论文，方法仍是 ColPali）

Jina：  v1 → v2 → v3 → v4（MLLM）→ v5-text → v5-omni
              ├─ jina-clip v1/v2（CLIP 双塔，并行）
              ├─ reranker v3（列表精排）→ v3.5
              └─ jina-colbert-v2（多语 MaxSim，并行于单向量 v3）

数据工程： 文档扩展 Doc2Query → Doc2Query++
           伪标签 GPL → R-GPL（蒸馏中重挖难负例）
           少样本 InPars → InPars-v2；Promptagator 独立
           离线改写：长尾电商；两步任务合成：E5-Mistral
           难负例：BM25/in-batch → ANCE → RocketQA → NV-Retriever → Conan

    ColQwen3 是社区换骨干，方法论文仍以 ColPali 为准。
