    Embedding 学习文档¶

    按“技术总览 → 机制专题 → 原论文研读”组织 Embedding 学习内容。Markdown 为权威正文；HTML 版由 scripts/site/site.sh build 统一生成，不入库。

    单篇/系列精读与论文 PDF、中译、figs/ 放在同一方法文件夹（如 GTE/GTE系列详解.md、InternLM2/InternLM2数据处理与过滤详解.md）。总览、合写、索引仍在本目录。报告嵌入图在 figures/<短名>/。

    Notion：Embedding&Rerank → Paper 库，一篇论文一个完整阅读页 + ModelCard mention；过程记录不创建子页。写作参照 论文阅读笔记指南，权限与落点见根目录 AGENTS.md。

    总览与技术专题¶

    要学习的内容 入口与分工
    表示、训练、评测与部署的完整框架 Embedding 总览，同时承接稀疏检索、Late Interaction、指令非对称编码、污染防控和向量压缩的跨论文解释
    技术演进、系列节点与代表性成绩 发展趋势、逐项时间线；同时保留阶段概览和模型规格卡，区分论文首发、模型发布与正式发表
    图文架构与交互方式 图文技术综述：双塔、融合、MLLM 与视觉文档路线；模型规格需结合各篇报告核对
    图搜图／文搜图的数据与训练 图搜图与文搜图表示学习：实例／语义标签、图文损失、多教师蒸馏、≤0.6B 约束和部署
    对比表示学习的经典综述 Lilian Weng《Contrastive Representation Learning》中英对照：对比损失、数据增强、难负例、视觉与语言的自监督路线
    Embedding 损失、监督组织与梯度 Embedding 损失函数精讲：Triplet／N-pair／MS／Circle、InfoNCE／NT-Xent／SupCon、alignment／uniformity、回归／类别代理／蒸馏；结合 GradCache 区分大候选集合与梯度累积
    假负例、难例和动态刷新 难负例实践；具体算法看 ANCE、RocketQA、NV-Retriever
    分数、排序与特征蒸馏 Embedding 蒸馏专题，结合 Margin-MSE 与 多语 SBERT
    领域标签和适配课表 领域适配实践，按科学、生物、代码、法律与推荐回查案例
    原论文、官方实现、博客和未覆盖材料 统一资料清单；现有研读入口在下面各表，不把仅收录链接算作完成研读

    按问题选读即可：先掌握“骨干／表示／交互／读出”，再读任务所需的专题。经典工作可沿 Sentence-BERT → DPR 理解句向量与问答检索的差异；RAG、FiD、BEIR 等衔接材料的覆盖情况见经典论文清单。
